2. Funktionsweise der App

Soundboard NG ist eine kostenlose Open-Source-Anwendung zur Wiedergabe und Organisation von Audiodateien auf Android-Geräten. Die App funktioniert vollständig offline und benötigt weder ein Benutzerkonto noch eine Internetverbindung.

Soundboard NG enthält keine Werbung und keine Analyse- oder Tracking-SDKs. Die App übermittelt keine Nutzungsdaten, Audiodateien oder Soundboard-Konfigurationen an Server des Entwicklers.

3. Lokal gespeicherte Daten

Die App speichert Soundboard-Konfigurationen, Einstellungen und Referenzen auf ausgewählte Audiodateien lokal auf dem Gerät. Bei bestimmten Importvorgängen werden Audiodateien in den internen App-Speicher kopiert.

Vor einem Konfigurationsimport kann die App eine lokale Wiederherstellungsdatei mit dem Namen soundboard-before-import.json anlegen.

Diese Daten werden für die vom Nutzer gewählten Funktionen der App verarbeitet. Die App übermittelt sie nicht selbst an externe Server.

4. Dateizugriff und Berechtigungen

Soundboard NG verwendet Androids Systemdialoge zur Auswahl von Dateien und Ordnern. Der Zugriff erfolgt auf Grundlage der vom Nutzer erteilten Zugriffsberechtigungen.

Für die Audiowiedergabe im Hintergrund verwendet die App einen Medienwiedergabedienst. Auf Android 13 und neuer kann die App um Erlaubnis für Benachrichtigungen bitten. Weitere technische Berechtigungen betreffen unter anderem das Aktivhalten des Geräts und die Abfrage des Netzwerkstatus.

Die App besitzt keine Android-INTERNET-Berechtigung.

5. Android-Systembackup

Abhängig von Android-Version, Gerätekonfiguration und Backup-Einstellungen können bestimmte lokal gespeicherte App-Daten durch die Backup-Funktionen des Betriebssystems gesichert oder auf ein anderes Gerät übertragen werden.

Die Soundboard-Konfiguration im AndroidX-DataStore-Verzeichnis ist durch die Backup-Regeln der App vom automatischen Android-Systembackup ausgeschlossen.

Intern gespeicherte Audiodateien im Verzeichnis backup-audio sowie die lokale Wiederherstellungsdatei sind derzeit nicht ausdrücklich von diesen Systembackups ausgeschlossen.

Ob und wie Android solche Daten sichert, hängt von den Funktionen und Einstellungen des Betriebssystems und des jeweiligen Backup-Anbieters ab.

6. Manueller Import und Export

Soundboard NG bietet Funktionen zum Import und Export von Konfigurationen und Sicherungsdateien. Speicherort und Weitergabe exportierter Dateien werden vom Nutzer bestimmt.

7. Speicherdauer und Löschung

Lokal gespeicherte Daten bleiben grundsätzlich bestehen, solange sie für die Nutzung der App benötigt und nicht durch den Nutzer oder die App gelöscht werden. App-Daten können über die Android-Systemeinstellungen gelöscht werden. Selbst exportierte Dateien sowie mögliche Systembackups sind gegebenenfalls separat zu löschen.

8. Google Play und diese Webseite

Bei der Installation über Google Play kann Google unabhängig von Soundboard NG personenbezogene Daten verarbeiten. Dafür gelten die Datenschutzinformationen von Google.

Diese Datenschutzerklärung wird über GitHub Pages bereitgestellt. Beim Abruf der Webseite kann GitHub technische Verbindungsdaten verarbeiten. Diese Verarbeitung ist von der lokalen Datenverarbeitung durch Soundboard NG zu unterscheiden. Weitere Informationen enthält die Datenschutzerklärung von GitHub.

9. Rechte betroffener Personen

Soweit personenbezogene Daten verarbeitet werden und die gesetzlichen Voraussetzungen vorliegen, bestehen insbesondere Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung und gegebenenfalls Datenübertragbarkeit sowie das Recht auf Beschwerde bei einer zuständigen Datenschutzaufsichtsbehörde.

2. How the App Works

Soundboard NG is a free, open-source Android application for organizing and playing audio files. It works entirely offline and requires neither an account nor an internet connection.

Soundboard NG contains no advertisements, analytics SDKs, or tracking SDKs. The app does not transmit usage data, audio files, or soundboard configurations to servers operated by the developer.

3. Locally Stored Data

The app stores soundboard configurations, settings, and references to selected audio files locally on the device. Certain import operations copy audio files into the app's internal storage.

Before importing a configuration, the app may create a local recovery file named soundboard-before-import.json.

This data is processed to provide the features selected by the user. The app does not transmit it to external servers.

4. File Access and Permissions

Soundboard NG uses Android's system file and folder pickers. Access is based on permissions granted by the user.

The app uses a media playback foreground service to continue audio playback in the background. On Android 13 and later, it may request notification permission. Other technical permissions include keeping the device awake and checking network connectivity status.

The app does not have the Android INTERNET permission.

5. Android System Backups

Depending on the Android version, device configuration, and backup settings, certain locally stored app files may be included in operating-system backups or device transfers.

The soundboard configuration stored in the AndroidX DataStore directory is excluded from automatic Android system backups by the app's backup rules.

Internally stored audio files in the backup-audio directory and the local recovery file are currently not explicitly excluded from Android system backups.

Whether and how these files are backed up depends on the operating system and the backup provider's settings and capabilities.

6. Manual Import and Export

Soundboard NG provides configuration and backup import/export functions. Users choose where exported files are stored and whether to share them.

7. Retention and Deletion

Locally stored data generally remains available until it is no longer needed or is deleted by the user or the app. App data can be deleted through Android system settings. Manually exported files and possible system backups may need to be deleted separately.

8. Google Play and This Website

When installing the app through Google Play, Google may independently process personal data under its own privacy policies.

This privacy policy is hosted on GitHub Pages. GitHub may process technical connection data when visitors access this website. This is separate from data processing performed locally by Soundboard NG. For more information, see the GitHub Privacy Statement.

Individuals may also lodge a complaint with a competent data protection supervisory authority.
